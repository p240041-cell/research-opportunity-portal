# University Research Opportunity Portal

A web-based Research Opportunity Portal developed for managing university research opportunities.

## Features

- Create research opportunities
- View all research opportunities
- View complete details of an opportunity
- Update existing opportunities
- Change opportunity status from Open to Closed
- Delete opportunities
- Basic frontend form validation
- Success and error messages
- REST API backend
- MySQL database
- Postman API testing

## Technologies

### Backend
- Node.js
- Express.js
- MySQL
- mysql2
- CORS
- dotenv

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap
